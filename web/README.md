# Vidyalaya OS web app

Next.js (App Router) + TypeScript + Tailwind. One responsive app for every role, installable on phones.

```bash
npm install
npm run dev        # http://localhost:3000, forwards /api to the Django API on :8000
npm run lint
npm run build
```

Set `API_URL` to point the `/api` proxy at a different API address. See the main README for the full setup.
